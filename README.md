# AgentWriter

Source-aware article drafting with durable runs, transparent evidence and human review.

This repository contains the initial application foundation. Production readiness remains unverified.

- `src/agentwriter/` — API, writing workflow, providers, storage and browser application.
- `migrations/` — PostgreSQL schema migrations.
- `tests/` — automated behavior and integration checks.
- `scripts/` — developer and verification utilities.
